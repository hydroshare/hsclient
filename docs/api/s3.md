# S3 Access

`hsclient` can read and write a resource's files directly over the S3 protocol, using
[s3fs](https://s3fs.readthedocs.io/).

## Requirements

- Authenticate with a **username and password** (`HydroShare(username=..., password=...)` or `HydroShare().sign_in()`).
  On sign-in, `hsclient` requests S3 credentials from HydroShare (`/hsapi/user/service/accounts/s3/`)
  and creates an `s3fs.S3FileSystem` client.
- With OAuth2 token authentication no S3 client is created: `s3_client` is `None` and the S3 methods raise an
  exception saying the S3 client is not available.
- The S3 endpoint defaults to `https://s3.hydroshare.org`. Override it with the `s3_endpoint_url` argument of
  `HydroShare(...)`.

## Paths

All `file_path` / `folder_path` arguments are relative to the resource's contents root.
`Resource.s3_path` is the underlying `bucket/prefix` of the resource.
`s3_file_download` and `s3_file_delete` raise `FileNotFoundError` if the file does not exist, and
`s3_file_upload` raises it if the local file does not exist. `s3_file_upload` and `s3_file_delete` refresh the
resource's metadata afterwards.

## Example

```python
from hsclient import HydroShare

hs = HydroShare(username="user", password="pass")
res = hs.resource("<resource_id>")

res.s3_list_objects(recursive=True, include_folders=False)    # ['data.csv', 'subfolder/file.txt']
res.s3_file_upload("local.txt", folder="subfolder")           # 'subfolder/local.txt'
res.s3_file_download("subfolder/local.txt", "/tmp")           # '/tmp/local.txt'
res.s3_file_delete("subfolder/local.txt")

hs.get_resource_path("<resource_id>")                         # 'bucket/prefix'
```

## Using the S3 client directly

`HydroShare.s3_client` (and `Resource.s3_client`) is a plain [s3fs](https://s3fs.readthedocs.io/)
`S3FileSystem`, so you can use it without going through a `Resource` object. Get the resource's `bucket/prefix`
with `HydroShare.get_resource_path` (or `Resource.s3_path`) and join file paths onto it yourself.

```python
from hsclient import HydroShare

hs = HydroShare(username="user", password="pass")

base = hs.get_resource_path("<resource_id>")                  # 'bucket/prefix'

hs.s3_client.ls(base)                                         # list the resource's top-level entries
hs.s3_client.exists(f"{base}/data.csv")                       # True / False

with hs.s3_client.open(f"{base}/data.csv", "rb") as f:        # stream a file without downloading it first
    header = f.readline()

hs.s3_client.get(f"{base}/data.csv", "/tmp/data.csv")         # download to a local file
```

**Note:** Unlike the `Resource.s3_*` methods, calls made directly on `s3_client` do not validate the path and do not
refresh the resource's metadata after a write. `s3_client` is `None` when you authenticate with an OAuth2 token.

## HydroShare

::: hsclient.hydroshare.HydroShare
    options:
      members:
        - s3_client
        - get_resource_path

## Resource

::: hsclient.hydroshare.Resource
    options:
      members:
        - s3_client
        - s3_path
        - s3_list_objects
        - s3_file_download
        - s3_file_upload
        - s3_file_delete
